## 🗂️ Why These Files Were Archived

These documentation files were created during various phases of the project:

1. **Multiple deployment approaches** were tested and documented
2. **CI/CD pipeline evolved** through several iterations
3. **Infrastructure changes** from DuckDNS to AWS EC2 to GitHub Pages
4. **Version management** shifted from multiple versions to single 2026.1 release
5. **Security cleanup** removed sensitive data and simplified structure

The current deployment is streamlined and uses:
- **GitHub Pages** for public documentation
- **Mike** for version management (single version: 2026.1)
- **GitHub Actions** for automated deployment
- **AWS EC2** for optional nginx hosting (manual deployment)
